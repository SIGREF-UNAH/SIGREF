# Sistema de Gestión de la Receptoría de Fondos (SIGREF)
![React](https://img.shields.io/badge/React-61DAFB?style=flat-square&logo=react&logoColor=black)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![Visual Studio Code](https://img.shields.io/badge/Visual%20Studio%20Code-007ACC?style=flat-square&logo=visual-studio-code&logoColor=white)

**Descripción:**  
SIGREF es una plataforma destinada a modernizar la gestión y control de ingresos en servicios médicos. Permite registrar ingresos, capturar datos de pacientes, generar reportes administrativos, controlar usuarios y administrar la información siguiendo estándares de salud (HL7/FHIR).  

> [!NOTE]  
> Este proyecto sigue los estándares **HL7** y **FHIR R5**, siendo nuestra aplicación un **sistema FHIR-LIKE**, no un sistema FHIR completo.  


El proyecto está desarrollado con **React** en el frontend, **C# (.NET 8)** en el backend y **TypeScript** en la capa de frontend. El repositorio contiene ambas partes separadas en carpetas principales: `/frontend` y `/backend`.
